## Database Strategy (from STACK.md)

**Drizzle ORM with PostgreSQL:** Schema defined in TypeScript, migrations via SQL files. PostgreSQL is the source of truth; Drizzle is the query builder.

**Dev workflow:** Use `better-sqlite3` locally for zero-setup dev, switch to PostgreSQL (pg driver) via DATABASE_URL env var for staging/production.

**Schema (from requirements):**
```
users              id, email (unique), passwordHash, tier (free|pro), createdAt, updatedAt
refresh_tokens     id, userId (FK), tokenHash, expiresAt, createdAt, revokedAt (nullable)
```

**Packages (from STACK.md):**
- drizzle-orm: 0.45.2
- drizzle-kit: 0.31.10 (devDep)
- pg: 8.21.0 (PostgreSQL driver)
- @types/pg: ~8.11.x (devDep)

Note: Phase 6a (this phase) implements database schema. Phase 6b handles migrations and multi-instance concerns.

## Type Organization

Database types live in `backend/src/types/database.ts` (ORM entity types, not request/response). Auth types remain in `backend/src/types/auth.ts` (JWT payloads, public interfaces).

## ESM Import Pattern

Drizzle imports with `.js` extensions per backend ESM requirement. Example: `import { usersTable } from './schema.js'`

  <name>Task 2: Create database schema with Drizzle</name>
  <files>backend/src/db/schema.ts</files>
  <action>
    Create `backend/src/db/schema.ts` with Drizzle table definitions for users and refresh_tokens.
    
    **Requirements:**
    
    **users table:**
    - id: PRIMARY KEY, UUID v4, auto-generated
    - email: VARCHAR(255), UNIQUE, NOT NULL
    - passwordHash: VARCHAR(255), NOT NULL (bcrypt hash, always 60 chars)
    - tier: ENUM('free', 'pro'), default 'free'
    - createdAt: TIMESTAMP WITH TIME ZONE, auto-set on insert
    - updatedAt: TIMESTAMP WITH TIME ZONE, auto-set on insert/update
    
    **refresh_tokens table:**
    - id: PRIMARY KEY, UUID v4, auto-generated
    - userId: UUID, FOREIGN KEY → users.id, ON DELETE CASCADE
    - tokenHash: VARCHAR(255), NOT NULL (hash of JWT token)
    - expiresAt: TIMESTAMP WITH TIME ZONE, NOT NULL
    - createdAt: TIMESTAMP WITH TIME ZONE, auto-set on insert
    - revokedAt: TIMESTAMP WITH TIME ZONE, nullable (NULL = not revoked, timestamp = revoked)
    
    **Indexes:**
    - users(email) — for login by email lookup
    - refresh_tokens(userId) — for finding all tokens per user
    - refresh_tokens(expiresAt) — for cleanup queries (phase 6b)
    
    **File format (Drizzle schema):**
    ```typescript
    import { pgTable, pgEnum, uuid, varchar, timestamp, text } from 'drizzle-orm/pg-core'
    
    export const tierEnum = pgEnum('tier', ['free', 'pro'])
    
    export const usersTable = pgTable('users', {
      id: uuid('id').primaryKey().defaultRandom(),
      email: varchar('email', { length: 255 }).notNull().unique(),
      passwordHash: varchar('password_hash', { length: 255 }).notNull(),
      tier: tierEnum('tier').notNull().default('free'),
      createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
      updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
    })
    
    export const refreshTokensTable = pgTable('refresh_tokens', {
      id: uuid('id').primaryKey().defaultRandom(),
      userId: uuid('user_id').notNull().references(() => usersTable.id, { onDelete: 'cascade' }),
      tokenHash: varchar('token_hash', { length: 255 }).notNull(),
      expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
      createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
      revokedAt: timestamp('revoked_at', { withTimezone: true }),
    }, (table) => ({
      userIdIdx: index('refresh_tokens_user_id_idx').on(table.userId),
      expiresAtIdx: index('refresh_tokens_expires_at_idx').on(table.expiresAt),
    }))
    ```
    
    **Why this structure:**
    - UUID PK: Standard for SaaS (partition-friendly, no sequential IDs)
    - Tier enum: PostgreSQL enforces allowed values, smaller than VARCHAR in database
    - tokenHash not plaintext: Never store JWT plaintext in database (same as password)
    - revokedAt nullable: Can distinguish "revoked" (timestamp) from "not revoked" (null) in queries
    - Indexes on userId and expiresAt: Query optimization for common lookups and cleanup

    **Step 3: Create client file**
    - Import drizzle-orm: `import { drizzle } from 'drizzle-orm/node-postgres'`
    - Import pg Client: `import { Client } from 'pg'`
    - Import schema: `import * as schema from './schema.js'`
    - Import config: `import config from '../config/env.js'`
    
    **File format:**
    ```typescript
    import { drizzle } from 'drizzle-orm/node-postgres'
    import { Client } from 'pg'
    import * as schema from './schema.js'
    import config from '../config/env.js'
    
    let client: Client | null = null
    let db: ReturnType<typeof drizzle> | null = null
    
    export async function initializeDatabase() {
      if (db) return db // Already initialized
      
      client = new Client({
        connectionString: config.databaseUrl,
      })
      
      try {
        await client.connect()
        console.log('✓ Database connected')
        db = drizzle(client, { schema })
        return db
      } catch (error) {
        console.error('✗ Database connection failed:', error)
        throw error
      }
    }
    
    export function getDatabase() {
      if (!db) {
        throw new Error('Database not initialized. Call initializeDatabase() first.')
      }
      return db
    }
    
    export async function closeDatabase() {
      if (client) {
        await client.end()
        console.log('✓ Database connection closed')
      }
    }
    ```
    
    **Why this pattern:**
    - Lazy initialization: Database connects on first use, not at module load (cleaner error handling)
    - Singleton pattern: One db instance per app
    - Graceful shutdown: closeDatabase() can be called on SIGINT
    - Schema import: All tables available in queries via schema

    **Step 1: Create database.ts types**
    ```typescript

    export type User = typeof usersTable.$inferSelect
    export type NewUser = typeof usersTable.$inferInsert
    ```
    
    This uses Drizzle's `$inferSelect` and `$inferInsert` to auto-generate types matching the schema (DRY, always in sync).
    
    **Step 2: Create userService.ts functions**
    
    - createUser(email: string, passwordHash: string): Promise<User>
      - Insert new row into usersTable with email, passwordHash, tier='free'
      - Return created user object
      - Throw error if email already exists (unique constraint violation)
    
    - findUserByEmail(email: string): Promise<User | null>
      - Query usersTable WHERE email = email
      - Return user object or null
      - No throw, return null for not found
    
    - findUserById(id: string): Promise<User | null>
      - Query usersTable WHERE id = id
      - Return user object or null
    
    - updateUserTier(userId: string, tier: 'free' | 'pro'): Promise<User>
      - Update usersTable SET tier = tier WHERE id = userId
      - Return updated user object
      - Throw error if user not found (optional, or return null — use null for consistency)
    
    **File format:**
    ```typescript
    import { eq } from 'drizzle-orm'
    import { usersTable } from '../db/schema.js'
    import { getDatabase } from '../db/client.js'
    import type { User } from '../types/database.js'
    
    export async function createUser(email: string, passwordHash: string): Promise<User> {
      const db = getDatabase()
      const [user] = await db.insert(usersTable).values({
        email,
        passwordHash,
        tier: 'free',
      }).returning()
      return user
    }
    
    export async function findUserByEmail(email: string): Promise<User | null> {
      const db = getDatabase()
      const [user] = await db.select().from(usersTable).where(eq(usersTable.email, email))
      return user || null
    }
    
    export async function findUserById(id: string): Promise<User | null> {
      const db = getDatabase()
      const [user] = await db.select().from(usersTable).where(eq(usersTable.id, id))
      return user || null
    }
    
    export async function updateUserTier(userId: string, tier: 'free' | 'pro'): Promise<User> {
      const db = getDatabase()
      const [user] = await db.update(usersTable)
        .set({ tier })
        .where(eq(usersTable.id, userId))
        .returning()
      return user
    }
    ```
    
    **Why this structure:**
    - Uses Drizzle query builder (not raw SQL, type-safe)
    - getDatabase() called inside each function (lazy database load)
    - findBy* returns null instead of throwing (cleaner calling code)
    - Type inference via $inferSelect ensures types match schema automatically

  <name>Task 5: Create RefreshToken service (token storage and revocation)</name>
  <files>backend/src/services/refreshTokenService.ts, backend/src/types/database.ts</files>
  <action>
    Create `backend/src/services/refreshTokenService.ts` with three functions for refresh token management. Update `backend/src/types/database.ts` to export RefreshToken types.
    
    **Step 1: Update database.ts types**
    ```typescript
    import type { refreshTokensTable } from '../db/schema.js'
    
    export type RefreshToken = typeof refreshTokensTable.$inferSelect
    export type NewRefreshToken = typeof refreshTokensTable.$inferInsert
    ```
    
    **Step 2: Create refreshTokenService.ts functions**
    
    - createRefreshToken(userId: string, tokenHash: string, expiresAt: Date): Promise<RefreshToken>
      - Insert new row into refreshTokensTable
      - Return created token record
    
    - findRefreshToken(tokenHash: string, userId: string): Promise<RefreshToken | null>
      - Query refreshTokensTable WHERE tokenHash = tokenHash AND userId = userId AND revokedAt IS NULL
      - Return token record or null
      - Check not expired: expiresAt > now()
    
    - revokeRefreshToken(tokenHash: string): Promise<void>
      - Update refreshTokensTable SET revokedAt = NOW() WHERE tokenHash = tokenHash
      - Called on logout
    
    **File format:**
    ```typescript
    import { and, eq, isNull, gt } from 'drizzle-orm'
    import { refreshTokensTable } from '../db/schema.js'
    import { getDatabase } from '../db/client.js'
    import type { RefreshToken } from '../types/database.js'
    
    export async function createRefreshToken(
      userId: string,
      tokenHash: string,
      expiresAt: Date
    ): Promise<RefreshToken> {
      const db = getDatabase()
      const [token] = await db.insert(refreshTokensTable).values({
        userId,
        tokenHash,
        expiresAt,
      }).returning()
      return token
    }
    
    export async function findRefreshToken(
      tokenHash: string,
      userId: string
    ): Promise<RefreshToken | null> {
      const db = getDatabase()
      const [token] = await db.select().from(refreshTokensTable).where(
        and(
          eq(refreshTokensTable.tokenHash, tokenHash),
          eq(refreshTokensTable.userId, userId),
          isNull(refreshTokensTable.revokedAt),
          gt(refreshTokensTable.expiresAt, new Date()),
        )
      )
      return token || null
    }
    
    export async function revokeRefreshToken(tokenHash: string): Promise<void> {
      const db = getDatabase()
      await db.update(refreshTokensTable)
        .set({ revokedAt: new Date() })
        .where(eq(refreshTokensTable.tokenHash, tokenHash))
    }
    ```
    
    **Why this pattern:**
    - findRefreshToken checks both revocation status AND expiration (defensive queries)
    - revokeRefreshToken is idempotent (can be called multiple times safely on logout)
    - tokenHash uniqueness enforced by database (though not declared as UNIQUE in schema for flexibility)
    - expiresAt comparison uses > now(), not >=, so expired tokens are never used
  </action>
